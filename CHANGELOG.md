# Changelog

## 1.0.0-1 — Public Beta 1

First public-beta release of SadlerACME for x86_64 Synology DSM using Cloudflare DNS-01.

Includes wildcard and multi-domain certificates, guided setup and recovery, DSM deployment, managed renewal checks, recovery backups, uninstall preparation, diagnostic logs and light/dark themes.

The first public release incorporates the accepted native window-position/size handling and wizard scrollbar clearance. Public documentation and installed guides are aligned with this release. The certificate, worker, scheduler and lifecycle implementation is unchanged by the release promotion.

See [RELEASE-NOTES.md](RELEASE-NOTES.md) for scope and limitations and [VALIDATION.md](VALIDATION.md) for evidence. Development-era changelogs are retained outside this public documentation set rather than being presented as public release history.
