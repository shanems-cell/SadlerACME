# Source edition — SadlerACME 1.0.0-1

This archive contains the corresponding source for Public Beta 1, with original project credit for Shane Sadler.

Build inputs are `src/`, `pkg/`, `tools/`, `build-spk.sh`, pinned `vendor/` material, LICENSE and NOTICE.txt. The worker, CGI extensions and standalone recovery helper are assembled during the build. Run the assembled helper, never its raw template.

Current entry documents are README.md, QUICKSTART.md, WORKFLOW.md, RECOVERY.md, RELEASE-NOTES.md and VALIDATION.md. Development-era histories, historical test screenshots and earlier test transcripts are not redistributed as current documentation. The selected original screenshots in docs/images are retained as illustrations and may show an earlier version. Their unchanged originals remain in the development archive; earlier tests have not been relabelled as tests of this release.

Current test scripts are included. Optional native-definition placement tests require separately supplied proprietary DSM reports; these reports are not included. The default self-contained contract model remains available. Browser tests use synthetic state and block external requests. No real tokens, certificates or keys are bundled for setup.

Third-party versions and licence identifiers are preserved: removing old SadlerACME release labels does not mean changing the upstream engine version, DSM prerequisites or legal notices.
